# Reagent

Reagent is a native Android endpoint-testing application built with Kotlin and Jetpack Compose.

The app lets users enter an HTTP endpoint, execute a request, inspect the result, and keep a local history of previous tests.

## Features

- Execute HTTP `GET` requests
- Paste endpoint URLs from the clipboard
- Show response status, duration, timestamp, URL, and body
- Persist request history locally with Room
- Delete individual results with a swipe gesture
